# AirBnB Clone - The Console

## Description
This is the first step to an aribnb clone project: a command interpreter to manage airbnb objects (User, States, City, Place, etc.) including creating, storing, and manipulating them via a custom shell. 

## Command Interpreter

### How to start
./console.py for interactive mode
echo "help" | ./console.py for non-interactive mode. 

### How to use it
help - 
create -
show -
destroy -
all -
update - 
quit -
EOF -


### Examples
$ ./console.py
(hbnb) help

Documented commands (type help <topic>):
========================================
EOF  help  quit

(hbnb) quit
